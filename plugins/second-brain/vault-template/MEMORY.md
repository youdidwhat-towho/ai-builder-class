# MEMORY: open decisions

Things waiting on you. Not tasks, not notes, not a log. Decisions that are
parked because only you can make them.

This file gets read at the start of every session, so anything parked here
comes back to you instead of dying with the conversation that raised it.

An entry leaves the moment it is decided. The decision goes in a daily note
or the file it belongs to. **This is a queue, not a history.**

## What this file is not

Each of these lives somewhere better. Putting them here is how this file
rots into a junk drawer that nobody reads.

| Not this | Where it goes |
|---|---|
| What happened today | `daily/YYYY-MM-DD.md` |
| Facts about a project, a person, or a thing | That note |
| Rules for how I want to be worked with | `CLAUDE.md` |
| Every file that changed | `LEDGER.md` |
| Ideas I might do someday | `reference/` |
| Finished work | `archive/`, via `maintain` |

## Rules

1. **Short enough to reread.** If you would not read it at the start of a
   session, it is too long and the parking pass is overdue.
2. **Every entry gets a date and a consequence.** "Waiting on the lender"
   is not an entry. "Waiting on the lender since 8/14, and the option
   period ends 9/2" is.
3. **Delete what stopped being true.** An outdated entry here is worse than
   an empty file, because it gets read first and believed.
4. **Written at session close.** `tldr` and `end-of-day` put things here.
   You do not have to maintain it by hand.
