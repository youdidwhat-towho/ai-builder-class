# Intake

Whatever shape it arrives in, produce one clean file. The user should never
have to format anything or decide which folder it goes in.

## Steps

1. **Check whether it already exists.** Search the vault for the name, the
   person, or the subject before creating anything. If a file exists, append
   to it. Never create a second file for the same thing, and never silently
   overwrite one.

2. **Work out what it is.** Usually obvious from the content:

   | It is about | It goes in |
   |---|---|
   | A thing you are trying to finish | `projects/` |
   | A person | `people/` |
   | A call you made and why | `decisions/` |
   | A process you will run again | `operations/` |
   | Something worth keeping, no action attached | `reference/` |

   If it is genuinely ambiguous, put it in today's daily note and say so.
   `daily/` is always a safe landing. A note in the wrong folder is worse
   than a note in the capture log.

3. **Extract what is actually there.** Names, dates, numbers, who said what,
   what happens next.

4. **Leave blanks blank.** Do not write "TBD" or "unknown" in every empty
   field. An empty field reads as empty. A field full of TBD reads as noise.
   Put what you still need in one short checklist at the top instead.

5. **Never invent a value.** Not a number, not a date, not a name spelling.
   If they did not give it to you and you did not look it up, it is not in
   the file. A confident wrong value is the most expensive thing you can put
   in a second brain, because everything downstream trusts it.

6. **Use the template** in `_templates/` if one fits. Stamp
   `last_touched:` with today's date.

7. **Append one line to today's daily note** saying what came in and where
   it went. This is how they find it later when they have forgotten the
   filename.

## The part people miss

**Keep the source language.** If somebody explained why they are doing
something, or what they are worried about, write it in their words rather
than your summary of their words.

That line is worth more in six weeks than every structured field above it,
and it is the first thing lost when a messy paste gets cleaned up into a
form. Summaries preserve the facts and throw away the meaning.

## Then say one line

What you created, where it went, and what is still missing. Not a recap of
the content they just gave you.
