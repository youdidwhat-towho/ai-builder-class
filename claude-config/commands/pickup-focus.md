description: Resume one specific thread instead of the whole day. Give it a word and it loads only what relates to that.

Take everything after the command as the topic. If nothing was given, ask what
to focus on in one line and stop.

Search the last two weeks of `daily/` for that topic, case-insensitive and
partial matches included. Look at `## Handoff` sections first if any exist,
then checkpoints, then the rest of the note. Also check the matching note in
`deals/`, `contacts/`, or `properties/` if there is one.

Then tell me, about that thread only:

1. **Where it stands.** The last thing that actually happened, with its date.
2. **What is blocking it**, if anything, and who owes what.
3. **The next action.** One, not a list.

Read the linked notes rather than guessing from the mention. If a handoff
names a file, open it.

If nothing matches the topic, say so plainly and offer `/pickup` for the
broad view. Do not pad the answer with the rest of the week to fill space.
The whole point of this command is that it leaves things out.
