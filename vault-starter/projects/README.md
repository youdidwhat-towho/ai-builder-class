# projects/

One file per thing you are actively trying to finish.

**The test is whether you can say what done looks like in one sentence.** If
you cannot, it is an idea, and ideas live in `reference/` until they are not.

Each project carries its own log. Append only, dated, never rewritten.

Open questions that only you can answer do not belong buried in here. Put
them in `MEMORY.md`, which gets read at the start of every session, so the
question finds you instead of waiting for you to find it.

Finished projects move to `archive/` on the next `maintain` pass.
