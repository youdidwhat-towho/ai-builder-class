# Your second brain

This is a working vault, not an empty template. Open it in Obsidian and start using it.

## Five minutes to useful

1. Open Obsidian, **Open folder as vault**, pick this folder.
2. Open `CLAUDE.md` and fill in the four lines under **Who I am**. That is the
   highest-value five minutes you will spend today.
3. Point Claude at this folder (see `../docs/first-hour.md` if you are not sure how).
4. Open today's file in `daily/` and dump one real thing from your week into it.
   Messy is fine.
5. Ask Claude: **"what's in my daily note, and what should I do about it?"**

That is the whole loop. Capture, ask, act.

## Start every session with this

Type this as your first message, every time:

> read CLAUDE.md in my vault and follow it

**Why it matters:** `CLAUDE.md` holds your standing instructions. In some setups it
loads on its own. In others it is just a file sitting in a folder until something
reads it. One short sentence removes the guesswork, and it costs you two seconds.

If it loaded on its own, saying this changes nothing. If it did not, this is the
difference between a second brain and a chatbot with a folder.

## The one habit that makes this work

**Everything goes in `daily/` first.** Every note, every idea, every call recap.
Do not stop to decide where something belongs, because that decision is where
capture dies. Claude files it later.

## What goes where

- `daily/`: the front door. One file per day, append only.
- `deals/`: one file per live deal
- `contacts/`: people
- `properties/`: one card per property, kept forever, even on dead deals
- `reference/`: save anything, find it later
- `decisions/`: what you decided and why, so you stop re-deciding
- `operations/`: your processes and checklists
- `_templates/`: starting points. Copy, don't edit these.

## MEMORY.md

`MEMORY.md` is your current state: what you are working on right now, what you are
waiting on, what is stuck. Keep it short. It is the first thing to read when you
come back after a few days away.
