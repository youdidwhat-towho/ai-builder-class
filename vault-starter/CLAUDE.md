## What this vault is

This is my memory, not my filing cabinet. The point is that you know things about
my business that were never written down anywhere else, so I stop re-explaining
them.

## The folders

| Folder | Holds |
|---|---|
| `daily/` | Every capture, one file per day, append only. **This is the front door.** |
| `deals/` | One file per deal I am actually working |
| `contacts/` | Buyers, sellers, agents, lenders, contractors |
| `properties/` | One card per property, even after the deal dies |
| `reference/` | Anything I want to find later. Save first, sort never. |
| `decisions/` | Calls I made and why. Read these before re-deciding something. |
| `operations/` | How I do things. My checklists and processes. |

## Rules

1. **Capture goes in `daily/YYYY-MM-DD.md`, always.** Append with a timestamp. Never
   ask me which folder something belongs in. One door, no decisions.
2. **Before answering anything about a deal, person, or property, search the vault
   first.** Do not answer from memory of this conversation alone.
3. **When I tell you something about how I work, write it down here** in this file,
   under Rules. Ask me first. A correction I have to repeat is a bug in this file.
4. **Say what you don't know.** If the answer depends on something that was decided
   on a phone call and never written down, say so instead of guessing. Guessing
   confidently is the most expensive thing you can do here.
5. **Plain language.** No jargon unless I used it first.

## Coaching

Coaching callouts are on. Teach me as we work. Details in the `coaching-callouts`
skill. Do not turn them off unless I ask.
